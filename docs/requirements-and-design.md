# IntelliJ IDEA 小说阅读插件需求与设计

日期：2026-08-24

## 背景

用户正在使用 IntelliJ IDEA 2026.1.3。公开插件市场中已有的小说阅读插件因为版本兼容问题无法正常使用，因此本项目开发一个专门兼容该 IDE 版本的 IntelliJ Platform 插件。

根据 JetBrains 官方兼容性说明，IntelliJ Platform 2026.1 对应构建分支 `261`，运行时要求 Java 21。因此本插件第一版目标平台为 IntelliJ IDEA `2026.1.3`，插件兼容范围设置为 `sinceBuild = "261"`，暂不设置 `untilBuild`，后续如验证需要再收紧兼容范围。

2026-08-24 已查阅的参考资料：

- IntelliJ Platform 构建号范围：https://plugins.jetbrains.com/docs/intellij/build-number-ranges.html
- IntelliJ Platform Gradle Plugin 2.x：https://plugins.jetbrains.com/docs/intellij/tools-intellij-platform-gradle-plugin.html
- IntelliJ Platform Gradle Plugin 扩展配置：https://plugins.jetbrains.com/docs/intellij/tools-intellij-platform-gradle-plugin-extension.html

## 当前范围

第一版只聚焦 TXT 小说阅读；`0.4.0` 起增加 EPUB 本地阅读支持。

必须支持：

- 可安装到 IntelliJ IDEA 2026.1.3 的 IntelliJ Platform 插件。
- 可从 `Tools` 菜单打开插件。
- 提供 `Novel Reader` 工具窗口，默认锚定在右侧。
- 工具窗口包含“本地阅读”和“Neat Reader”两个 Tab。
- 支持在工具窗口内嵌 Neat Reader Web 端，默认打开 `https://www.neat-reader.cn/webapp`。
- 打开本地 `.txt` 和 `.epub` 文件。
- 尽量正确显示中文 TXT 内容。
- 尽量正确提取 EPUB 中 OPF spine 声明的 XHTML 正文。
- 尽量还原 EPUB 脚注和基础复杂排版，将其转换为适合当前纯文本阅读器的结构。
- 根据常见 TXT 章节标题识别章节。
- 支持上一章 / 下一章导航。
- 支持从章节选择框跳转章节。
- 支持字号调整。
- 支持行距调整。
- 支持系统字体选择，例如微软雅黑、宋体、仿宋、楷体、黑体等。
- 支持正文文字颜色选择。
- 支持阅读主题选择，例如跟随 IDE、护眼、纸张、暗色。
- 支持正文阅读宽度选择。
- 支持本章进度和全书进度显示。
- 支持基础阅读快捷键。
- 支持隐藏阅读区鼠标光标。
- 支持通过 `Tools -> Novel Reader` 子菜单在文字按钮和简略图标按钮之间切换。
- 支持章节边界连续滚动切换。
- 支持保存并恢复基础阅读状态。

当前暂不支持：

- PDF、MOBI 或在线书源。
- 书架管理。
- 云同步。
- 插件市场发布自动化。
- 复杂主题和排版预设。

## 交互设计

插件主界面是一个名为 `Novel Reader` 的工具窗口。

工具窗口 Tab：

- `本地阅读`：插件自带 TXT/EPUB 阅读器。
- `Neat Reader`：基于 IntelliJ JCEF 的内嵌浏览器，加载 Neat Reader Web 端；JCEF 不可用时显示提示并提供外部浏览器打开入口。
- `Neat Reader` Tab 按离散档位自动缩放：先由窗口宽度反推「站点看到的 CSS 视口宽度」再选档，带迟滞带；自动模式目标优先保证"不错版"（不出现宽屏窄列版式），并提供缩小、跟随窗口和放大按钮。
- `Neat Reader` Tab 的手动缩放会持久化并锁定，工具栏显示「已锁定」，点「跟随窗口」解锁回到自动换档；JCEF 浏览器延后到组件挂载时才创建。
- `Neat Reader` Tab 拦截 `window.open` 和 `target="_blank"` 新窗口请求，优先在当前内嵌 Tab 打开，避免弹出空白窗口。

顶部控件：

- 打开 TXT 或 EPUB 文件。
- 上一章。
- 章节选择。
- 章节选择器使用紧凑宽度，只显示可分辨章节序号的短标签，完整章节标题通过鼠标悬浮提示查看。
- 下一章。
- 设置展开 / 收起。

设置区默认隐藏，展开后显示：

- 字号减小。
- 字号增大。
- 行距减小。
- 行距增大。
- 字体选择。
- 文字颜色选择。
- 主题选择。
- 阅读宽度选择。
- 隐藏光标开关。

正文区域：

- 可滚动的纯文本阅读区域。
- 自动换行。
- 支持字号、行距、字体样式调整。
- 支持阅读主题和正文宽度调整。
- 支持正文文字颜色调整。
- 默认隐藏高级阅读设置，减少工具栏占用的垂直空间。
- 阅读区右侧保留额外选择缓冲区，避免行尾最后一个字贴近边界时无法用鼠标选中。
- 滚动到章节末尾后继续向下滚动，自动进入下一章。
- 滚动到章节开头后继续向上滚动，自动进入上一章末尾。
- 正文采用章节窗口化渲染，显示当前章节全文以及上下文预览，读者可以在章节边界附近同时看到上一章尾部和下一章开头。
- 支持 `Space`、`PageUp`、`PageDown`、`Alt + 左右方向键`、`Ctrl + =`、`Ctrl + -` 等快捷键。
- 支持选中文字后右键进行本地词典查找、汉典查词、百度搜索和复制，减少离开阅读器手动搜索的操作。

状态区域：

- 当前文件名。
- 当前章节序号和总章节数。
- 本章进度。
- 全书进度。
- 当前编码。

阅读位置记录：

- 以全书字符偏移 `globalOffset` 作为主要阅读位置，而不是仅依赖滚动条像素值。
- 保存偏移位置附近的原文片段 `anchorText`，用于恢复时校验和修正位置。
- 保存章节内千分比 `progressInChapterPermille`，用于 TXT 内容变化或锚点失效时兜底恢复。
- 保留旧字段 `scrollValue` 作为兼容兜底，避免旧版本升级后完全丢失阅读位置。
- 再次打开同一本 TXT 或 EPUB 时应视为继续阅读，不清空章节、全书 offset 和锚点。
- 工具窗口初始化或窗口重排期间，如果滚动条范围尚未可用，应延迟恢复阅读位置，并禁止把临时开头位置写回阅读记录。

## 技术设计

语言和构建：

- Kotlin
- Gradle Kotlin DSL
- IntelliJ Platform Gradle Plugin 2.x
- Java toolchain 21

主要组件：

- `OpenNovelAction`：注册到 `Tools -> Novel Reader` 子菜单，打开小说文件选择器并激活工具窗口。
- `ToggleButtonStyleAction`：注册到 `Tools -> Novel Reader` 子菜单，在文字按钮和简略图标按钮之间切换阅读工具栏显示方式。
- `OpenNeatReaderAction`：注册到 `Tools -> Novel Reader` 子菜单，激活工具窗口并切换到 `Neat Reader` Tab。
- `NovelReaderToolWindowFactory`：创建工具窗口并安装阅读面板。
- `ReaderPanel`：基于 Swing 的阅读 UI，负责文件打开、章节导航、阅读样式控制和状态保存。
- `NeatReaderPanel`：基于 JCEF 的网页阅读面板，内嵌 Neat Reader Web 端，并提供 Web 端、官网、外部浏览器打开入口和浏览器级缩放控制。
- `BookLoader`：按文件扩展名分发到具体读取器。
- `TxtBookLoader`：TXT 文件读取器，支持编码回退。
- `EpubBookLoader`：EPUB 文件读取器，解析 `container.xml`、OPF manifest 和 spine，按阅读顺序提取 XHTML 正文。
- `ChapterParser`：基于常见中英文章节标题的简单章节解析器。
- `ReaderStateService`：项目级持久化状态，保存最后打开文件、编码、章节索引、滚动位置、字体、文字颜色、字号、行距、主题、阅读宽度、隐藏光标开关和按钮显示方式。

划词查找策略：

- 在阅读正文组件上挂载右键菜单。
- 菜单显示前读取当前选中文本，没有选中文本时禁用查词、搜索和复制入口。
- `本地词典查找` 使用 `chinese-xinhua` 的 `word.json` 和 `ci.json` 做离线精确匹配，查到时弹窗显示结果，查不到时弹窗提示未找到。
- `汉典查词` 打开 `https://www.zdic.net/hans/` 对应词条，适合中文生僻字词、成语和古文词汇。
- `百度搜索` 使用百度作为外部搜索兜底，适合本地词典和汉典未覆盖的专名或长句。
- 所有外部跳转都通过 IntelliJ Platform 的浏览器工具打开，不在插件内直接调用未公开接口。
- 本地词典和汉典查找默认截取前 80 个字符，百度搜索默认截取前 500 个字符，避免超长选区生成异常 URL。
- `chinese-xinhua` 数据按 MIT License 随插件资源打包，并在资源目录保留许可证文件。

章节滚动策略：

- 打开 TXT 后对整本书建立虚拟行布局，滚动条对应全书连续阅读高度，不再按章节替换正文组件内容。
- 阅读组件只绘制当前可见区域附近的行，章节边界不会触发 `JTextPane` 文本重设、段落样式重刷或窗口切换。
- 章节下拉框、上一章和下一章按钮只负责跳转到全书 offset；章节本身只是导航标记，不再作为渲染窗口边界。
- 滚动过程中根据可视区域内 25% 高度处的阅读锚点自动更新当前章节、章节进度和全书进度。
- 虚拟阅读组件自行处理鼠标拖选、选区高亮、复制和右键查词，替代 `JTextPane` 原生选区能力。
- 虚拟阅读组件在每行缓存字符横向位置，拖选命中和选区绘制基于缓存坐标，减少拖选时重复计算。
- 恢复阅读位置时优先使用 `globalOffset + anchorText`，不受窗口大小、字体、字重、行距和阅读宽度变化影响。
- 窗口大小、字号、行距、字体、字重或阅读宽度变化前，先锁定当前可视阅读锚点；连续缩放时延迟整本重排，重排期间暂停滚动条回写，重排完成后按全局阅读锚点重新定位，避免像素滚动值导致位置漂移。

TXT 编码策略：

1. 尝试 UTF-8。
2. 尝试 GB18030。
3. 尝试 GBK。
4. 全部失败时提示可读错误。

EPUB 解析策略：

1. 从 `META-INF/container.xml` 查找 OPF package 文件。
2. 读取 OPF manifest，筛选 XHTML/HTML 正文资源。
3. 按 OPF spine 中的 `itemref` 顺序拼接正文，避免按压缩包文件名排序造成章节错乱。
4. 优先使用 XHTML 中的 `h1`/`h2`/`h3` 或 `title` 作为章节标题，缺失时使用“第 N 章”兜底。
5. 将 XHTML 标签转换为增强纯文本段落，保留基础换行和常见 HTML 实体。
6. 识别脚注、尾注和注释块，正文脚注链接显示为 `[注N]`，章节末尾追加“【注释】”列表。
7. 将标题、列表、引用、表格、图片 alt、ruby 注音、粗体和斜体转换为纯文本可读结构。
8. 暂不完整还原 CSS、浮动布局、图片显示和跨文件复杂交互，后续如需要再引入更完整的 EPUB 渲染层。

章节解析策略：

- 匹配常见章节行，例如：
  - `第1章`
  - `第一章`
  - `第001回`
  - `Chapter 1`
- 如果没有识别到章节，将全文作为单章处理。

## Neat Reader 缩放档位设计

内嵌网页的缩放只走 JCEF 浏览器级 `zoomLevel`，不注入影响布局的 CSS。缩放档位由「站点看到的 CSS 视口宽度」反推：

```text
zoomFactor = 1.2 ^ zoomLevel
cssWidth   = 窗口像素宽 / zoomFactor
```

目标区间为 `[TARGET_CSS_WIDTH_MIN, TARGET_CSS_WIDTH_MAX]`：

- 窗口比下界窄 → 缩小渲染，给站点补足 CSS 像素；
- 窗口比上界宽 → **放大**渲染，把 CSS 像素压回上界以内。

注意方向：缩小渲染（zoomFactor < 1）会让站点以为窗口**更宽**，反而更容易触发宽屏版式，因此 0.4.6 的「最大 96%」与
"避开宽屏版式"的目标是相反的。用户已确认优先保证"不错版"（宁可字小，也不能出现宽屏窄列版式），档位表按此目标函数实现。

档位选择分三步：算理想倍率 → 量化到 `ZOOM_LEVEL_STEP` 网格（0.4 ≈ 7.6%，相邻档肉眼可辨） → 迟滞判定
（`HYSTERESIS_CSS_PX`，当前 cssWidth 仍在 `[MIN-H, MAX+H]` 内就不换档），因此临界附近不会反复抖动。

站点真实断点无法从代码推导，必须真机测量：拖动工具窗口宽度，从 IDE 日志里 `Neat Reader 缩放` / `Neat Reader 页面回报`
两行拿到 `cssWidth` 与站点实测 `innerWidth`，再回填 `TARGET_CSS_WIDTH_MIN` / `TARGET_CSS_WIDTH_MAX`。详细步骤见 `README.md`
的「Neat Reader 缩放调参」一节。
